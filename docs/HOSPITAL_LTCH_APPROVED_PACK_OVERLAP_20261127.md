# National Hospital and LTCH approved-pack overlap

Audited all published bytes of the Hospital and Long-Term Care Hospital packs from FacilitySignal main `3d9871cbe52ce8f561e79beff6985de0925af293`. The Git object digests and byte lengths were checked against the three retrieved objects before parsing, and SHA-256s are retained. These are the exact approved app projections, not new publisher CSV files; the [public release manifest](https://github.com/JeremyHennessy/FacilitySignal/blob/3d9871cbe52ce8f561e79beff6985de0925af293/web/public-directory/manifest.json) gives the limits and source-release dates.

The Hospital catalog contains 5,435 distinct CCNs and November 12 publisher release; the LTCH catalog contains 311 distinct CCNs and September 23 publisher release. Five CCN/state candidates appear in both, with no exact literal address/city/state/ZIP keys shared. For all five the city, state and ZIP are identical, and the LTCH address differs exactly by one terminal space-plus-hyphen. There were no other CCN conflicts or literal cross-source site matches. This isolates a formatting-only candidate class; it does not demonstrate when or why the marker was introduced, resolve current physical-site identity, justify transferring claims, or establish shared operations. The qualifier does not drop substantive address suffixes, and it makes no canonical merges.

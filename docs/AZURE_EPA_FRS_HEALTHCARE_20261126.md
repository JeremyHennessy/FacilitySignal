# EPA FRS / ECHO healthcare-sector coverage

Official data download: https://echo.epa.gov/tools/data-downloads ; field dictionary: https://echo.epa.gov/tools/data-downloads/frs-download-summary ; versioned observation from https://echo.epa.gov/files/echodownloads/frs_downloads.zip . EPA explicitly describes this as the ECHO FRS subset, not the complete national FRS. The three selected CSVs are facilities, NAICS codes, and program links. Source row counts are separate and fully reconciled; only reported six-digit sector 62 classifications, exact 12-digit registry key joins, and state/program aggregates are retained. Healthcare subsectors 621–623 and social assistance 624 are distinguished; one registry record can have multiple industry and program associations, so counts overlap and are not facility census counts. Raw data and scratch identifier tables are removed before publication to private Blob. No individual facility or linked asset rows, addresses, locations, permits, compliance status or source-record identifiers are retained. Weekly checks compare publisher HEAD metadata once a successful receipt is pinned. This is not full RCRA/NPDES/OSHA or state inspection ingestion. No production/public asset changes. Live source membership, encoding, header and row reconciliation must pass before any completed-source claim.

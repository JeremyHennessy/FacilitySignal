# RCRA and NPDES Part 1 aggregate coverage

Official EPA catalog https://echo.epa.gov/tools/data-downloads and directory https://echo.epa.gov/files/echodownloads/ confirm rcra_downloads.zip and npdes_downloads.zip. Data dictionaries https://echo.epa.gov/tools/data-downloads/rcrainfo-download-summary and https://echo.epa.gov/tools/data-downloads/icis-npdes-download-summary document exact source key relations. RCRA uses ID_NUMBER plus ACTIVITY_LOCATION; NPDES uses NPDES_ID or EXTERNAL_PERMIT_NMBR. Initial scopes screen NAICS, facility and selected inspection/evaluation, violation and enforcement tables; NPDES also screens the permit table. Count source rows separately, reconcile national totals, separate unresolved source keys, and retain only national aggregate evidence. No row-level identifiers, site-specific associations or compliance/inspection details retained. RCRA history, NPDES effluent Part 2 and monitoring data are explicitly excluded. This is not a unique facility census or complete regulatory coverage. Live publisher headers and all row reconciliations must pass before counting. Weekly metadata monitoring is ready for pinned receipts.

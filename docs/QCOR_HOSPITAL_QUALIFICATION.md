# QCOR hospital survey export qualification

Source FS-020, publisher CMS QCOR. Official report: https://qcor.cms.gov/Hospital_2567_Reports ; full XLSX export link observed in the official report: https://qcor.cms.gov/downloadHospital2567 . On 2026-11-25 the public report displayed 42,805 records with the default deficiency filter and 2010–2026 range; this is a changing UI count, not a verified bulk workbook row count. Official report exposes survey event identifiers, CCNs, provider identity/address, survey type/date and deficiency tags including physical environment, HVAC, fire safety, medical gas and equipment maintenance. The full export has not yet been reconciled against the report. The web tool cannot parse the XLSX response; a bounded isolated CI probe downloads and inventories the workbook, calculates SHA-256, identifies candidate headers, and retains aggregate audit only. No claim of ingestion or correction status. The export is not equivalent to an open violation list.

Additional QCOR official reports to qualify individually: CAH https://qcor.cms.gov/CAH_2567_Reports ; transplant https://qcor.cms.gov/Transplant_2567_Reports ; CLIA https://qcor.cms.gov/CLIA_2567_Reports ; rural health https://qcor.cms.gov/RHC_2567_Reports ; CORF https://qcor.cms.gov/CORF_2567_Reports ; PRTF https://qcor.cms.gov/PRTF_2567_Reports ; ICF-IID https://qcor.cms.gov/ICF-IID_2567_Reports ; EMTALA https://qcor.cms.gov/reportEMTALA.jsp . CMS QCOR homepage also confirms ASC, HHA, FQHC, X-ray, ESRD and hospice extracts. Check overlap across report families, memo tags, duplicate findings, source survey ID namespace, effective date and correction evidence; do not scrape thousands of pages when a bulk download exists. No raw survey narrative or patient information in public artifacts.

CMS POS enrichment: official QIES API documentation https://data.cms.gov/provider-characteristics/hospitals-and-other-facilities/provider-of-services-file-quality-improvement-and-evaluation-system/api-docs confirms Q3 2026 13,598 records and 473 columns; iQIES API docs https://data.cms.gov/provider-characteristics/hospitals-and-other-facilities/provider-of-services-file-internet-quality-improvement-and-evaluation-system/api-docs confirm 100,334 rows and 186 columns. iQIES publisher notes FQHC, RHC, PRTF and CMHC coverage added in Q3 2026. QIES column inventory includes CT_SCAN_SRVC_CD, SRGCL_ICU_SRVC_CD and DNTL_SRVC_CD, among others. Retrieve the official dictionaries and validate code meanings and applicability before deriving a service or asset claim. Do not infer equipment installation from a service indicator.

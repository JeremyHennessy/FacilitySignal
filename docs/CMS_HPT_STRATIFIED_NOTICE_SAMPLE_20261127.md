# FS-169 stratified three-notice review

Before opening the PDFs, this review selected three single-document rows from the [official CMS posting](https://www.cms.gov/priorities/key-initiatives/hospital-price-transparency/enforcement-actions): the first displayed row in the earliest notice-year stratum, the first displayed row in 2024, and the only displayed row marked under review. This is a narrow, deliberately stratified sample rather than a representative sample or a complete notice audit.

The official PDF renderer returned no matches for CCN, Certification Number, or Provider Number in all three (nine text searches). No labeled CCN was located. The published hospital directory pack, read from its pinned repository revision, supplied 5,435 addresses for comparison using the existing strict address gate. One notice had a unique address candidate. The other two were not keyable or not matched within this gate's deliberately narrow normalization; one street line included a comma before the directional suffix, and one used a dotted directional prefix where a contemporary directory candidate used an undotted prefix. Do not interpret these abstentions as proof of nonexistence or widen matching as a substitute for an explicit provider identifier. Both address-format boundaries now have synthetic regression examples. All three notices remain unlinked.

The previously reviewed two documents on one row also remain unlinked; no rates are inferred from five reviewed notices. Text searches do not establish absence from unrendered PDF fields. The under-review flag is a displayed label, not an independently confirmed final disposition. Sources were read only and no notice text, source rows, addresses, case identifiers, or provider identifiers were committed. This isolated audit does not change the public app or private storage.

# HRSA 340B covered entities — source qualification

FS-017. HRSA public Reports page https://340bopais.hrsa.gov/Reports/ and official FAQ https://340bregistration.hrsa.gov/help/CoveredEntity/Reports/Frequently%20Asked%20Questions%20-%20New%20CE%20Daily%20Report.htm describe automated downloads using a fresh public browser session and report button. Do not replay postbacks, authenticate, bypass access controls or request a hidden API. Download at most once, and only the official Excel report. The three-sheet report describes one row per covered-entity record, plus separate shipping and contract pharmacy worksheets: https://340bregistration.hrsa.gov/help/CoveredEntity/Reports/DailyReports.htm . Parse only Covered Entities; inspect CE ID, 340B ID, entity type and publisher participation status. Names, locations, shipping, contacts, pharmacy relationships, pricing and individual record data are not retained. No physical-site or current-compliance inference. Bound time and bytes, use temporary files only, preserve aggregate audit. Source-specific reuse review and durable storage pending. No UI change or added infrastructure.

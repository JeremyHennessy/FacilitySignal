It does not export or log identifiers, individual rows, address data, or property-ownership claims. It requires compatible report months and reconciles the four nationally retained table counts for enrollment and organization roles. A mismatch produces no report.

Each retained role row is counted once as source-scoped candidate, ambiguous enrollment/PAC provider evidence, missing enrollment/PAC, invalid identity, no directory candidate, or directory jurisdiction conflict. Multiple identical practice occurrences do not multiply role rows. Multiple directory states are held even when one agrees; multiple same-state directory sources do not prove one physical site. This national aggregate audit is not itself the public profile query and does not approve raw role publication or generalize to other sources. It cannot establish current control or ownership.

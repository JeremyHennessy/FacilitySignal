# Institutional observation search qualification (2026-11-26)

Scope: exact existing derived private archive, 101,534 values in ten source-specific fields and 27,592 provider records. No new data acquisition, source release, site merging, Azure mutation, or public application publication. The qualified local CLI requires the exact verified archived SQLite file; keep it on authorized private storage. Do not expose this CLI over a network.

Publisher evidence reviewed 2026-11-26:
- CMS general reuse: https://data.cms.gov/about and https://data.cms.gov/provider-data/topics/long-term-care-hospitals/about-using-government-data . Government-produced public data may be reused with source attribution, without implying endorsement. This does not authorize unrestricted release of other FacilitySignal records.
- Hospital General Information https://data.cms.gov/provider-data/dataset/xubh-q36u ; https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/hospital/HOSPITAL_Data_Dictionary.pdf page 20: emergency services column. Extracted October 2026 but rendered April 2026; exact field name and archived Yes/No domain agree. Treat only as snapshot reported flag, not actual emergency availability.
- Dialysis https://data.cms.gov/provider-data/dataset/23ew-n7w9 ; https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/dialysis/DF_Data_Dictionary.pdf page 3, independently corroborated historical dictionary https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/DF_Data_Dictionary.pdf . Current extracted release October 2026 / rendered January 2026 differs; meanings for chain owned or managed, late shift starting 17:00 or later, and three treatment/training flags agree across views and with exact archived headers. Do not infer equipment, contracts or current service availability.
- Nursing Provider Information https://data.cms.gov/provider-data/dataset/4pq5-n9py ; https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/nursing_home/NH_Data_Dictionary.pdf page 9. Current text October 2026 / rendered June 2026 differ, but both agree on ownership change in preceding 12 months, survey-age indicator, SFF/candidate/blank domain, and sprinkler coverage values. Treat as publisher-reported snapshot. The archived SFF blank remains not_reported, not a compliance conclusion; documented null interpretation is not promoted to a new negative value. Sprinkler dictionary includes No, but this exact archive contains only Yes, Partial and Data Not Available. Future unknown values fail closed.
- Reuse gate: only seven snapshot flags proposed for a future public candidate (hospital emergency, five dialysis fields and nursing ownership change). Preserve three nursing safety/oversight fields as authorized local only: sprinkler, survey age, special focus. No public row-level artifact or Pages update from this qualification. Candidate selection is a deliberately conservative product policy, not a claim of publisher restriction on these already publicly disclosed columns.

The workflow independently restores the exact archive, validates all source/directory membership, field definitions/domains, every national and state filter, pairwise filter combinations, deterministic pagination and sampled exact-record profiles. It outputs aggregate receipt only. Candidate JSON is temporary, with hash and count retained for later separate promotion. No private database, private values, or row-level candidate is uploaded. No new recurring schedule. Full consolidated archive readback is a separate workstream, not duplicated here.

Local CLI examples (authorized environment only; exact restored projection.sqlite3):
`python -m scripts.institutional_search search --database /private/projection.sqlite3 --source dialysis --state NY --filter late_shift=reported_yes --filter peritoneal_dialysis=reported_yes`
`python -m scripts.institutional_search profile --database /private/projection.sqlite3 --source nursing --ccn 000001 --state NY` (illustrative identifier, not a claim of a real match).

# HCRIS supplemental numeric archives

The seven verified report-index sources already preserve parent keys and per-report child counts. This stage adds exact decimal-text values and bounded source-native worksheet/line/column coordinates, scoped by form, annual member, source ordinal and parent report key. Match exact publisher bytes and the original private index receipt and database SHA, independently reconcile per-report child counts, aggregate coordinate/value states and member CRC, preserve repeated source coordinates. Unresolved parents and coordinate or numeric syntax exceptions are explicitly counted and never attached. No alpha text, names, financial units, measure semantics, facility identity inference or public data-pack changes. Parent references are copied for referential integrity, not counted as new source rows. Each supplemental scope is distinct from the previously retained report index; its source observations increase the retained-observation total, while its existing publisher release is not counted a second time.

Initial bounded scopes: all annual members for CMHC and RHC; annual member 2024 for FQHC, hospice and renal. Each scope has at most 4 million numeric input rows and a 350 MB database cap. Larger hospital and SNF FY2024 cells and remaining annual partitions require further bounded execution. Uses existing storage only; actual storage costs unverified. Weekly publisher metadata checks use parent source versions, not a second check for each supplemental projection. Live completion requires exact Blob readback and a separate updated consolidated inventory receipt.

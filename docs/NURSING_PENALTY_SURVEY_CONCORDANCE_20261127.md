# National nursing penalty and survey concordance

This offline audit adds a second dimension to the pinned nursing regulatory qualification without publishing individual records. The public directory contains only historical nursing health and fire citation totals, and has no penalty or survey-event pack. The private extension already contains the three historical source tables used here (15,007 penalty, 148,956 inspection-date, and 43,931 summary rows in the existing qualification). No source is downloaded or expanded by this adapter.

Pass only the exact, already restored, locally authorized extension database: `python -m scripts.nursing_penalty_survey_concordance --extension /path/to/extension.sqlite3`. The offline path fails closed on archive digest and source counts, uses SQLite read-only immutable mode, and rehashes after the audit. No Azure or network calls are implemented. Run synthetic tests with `python -m unittest discover -s tests -p test_nursing_penalty_survey_concordance.py`.

The output temporarily indexes exact source CCN/date candidates in memory. A penalty's own reported date, not its processing date or denial-start field, is compared with survey date fields. The summary's health and fire dates are kept as separate coverage fields; a summary's two dates or duplicate inspection-date observations do not multiply a penalty source row. The inspection-date source lacks raw state linkage. The summary retains a prior same-state classification but not the raw reported state. Rows without accepted directory linkage, strict calendar dates, or at/before-release dates are kept in separate unresolved buckets. These comparisons do not infer shared survey/event IDs, case chronology, settlement, payment, operating status, or current enforcement. The report contains no provider lists or source dates.

**Verification status:** Synthetic tests cover both counterpart source types, overlapping dates, date multiplicity, cross-provider and archived state conflicts, invalid and post-release dates, wrong-database rejection, and aggregate-only output. Exact private archive replay was not performed, so no new nationwide concordance result is asserted.

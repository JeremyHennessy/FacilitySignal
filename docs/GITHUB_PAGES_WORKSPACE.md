# GitHub Pages public research workspace

Owner requested GitHub Pages (2026-11-25). Existing Pages deploys main to https://jeremyhennessy.github.io/FacilitySignal/. The initial live-browser CMS API candidate 683520f6b9d5475f5f735ac31438bd69f5e2617e failed at publisher fetch in run 45700057053. Do not claim direct browser CMS access.

This replacement publishes a deliberately narrow derived directory from the already-qualified Care Compare artifact 15046953633, with hash, release lock, per-source row-count and integrity verification. The public government data reuse notice is https://data.cms.gov/provider-data/topics/hospitals/about-data/ and https://data.cms.gov/about. Attribute CMS and never imply government endorsement. Only institutional provider CCN, name, reported address, city/state/ZIP and source-reported capacity are retained. Nursing health/fire counts are aggregated by CCN/state. No raw CSV, contact information, ownership/chain projection, individual ownership, hospital survey narratives, certification rows, integrated database or customer data. Reuse review for other source families remains separate and pending.

Each provider/source shard is loaded independently and filtered in the browser; no integrated database is loaded. This is a bounded static research interface, not the authenticated dynamic application. Certification, QCOR and PECOS sections expose historical coverage and official source links only. Preserve all existing Python/SQLite routes, ingestion and source registers. Browser gate checks real qualified projections at four viewport widths, filtering, record detail and source evidence. The build is confined to the isolated branch until tests succeed; deployment requires current main comparison and expected-SHA preservation. No paid infrastructure.

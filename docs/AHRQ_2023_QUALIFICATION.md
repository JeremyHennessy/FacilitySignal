# AHRQ 2023 health-system affiliation source qualification

2026-11-25: official source page https://www.ahrq.gov/chsp/data-resources/compendium-2023.html provides five files; system file revised September 2025, plus nursing and home health linkage additions. The publisher lists 639 systems. The 2023 hospital technical documentation https://www.ahrq.gov/sites/default/files/wysiwyg/chsp/compendium/2023-hospital-linkage-techdoc.pdf gives 6,800 hospitals, 4,193 assigned to a Compendium system, 2,607 not assigned. The documentation explicitly notes CCN-sharing campuses are aggregated, excludes non-50-state/DC hospitals, and draws on 2022 AHA and 2023 IQVIA data; affiliations may lag mergers and acquisitions. A missing affiliation is not proof of independence. Preserve 2023 vintage, distinguish parent system affiliation from ownership, current operators, subsidiaries and physical sites, and do not infer property ownership or active status. Some underlying AHA data are restricted; do not publish derived row-level records or assume public file access grants commercial redistribution. Commercial-use review pending.

This diagnostic branch downloads exactly the official linked system/hospital/nursing/home-health CSVs and outpatient XLSX, verifies source format, records size, digest, header and aggregate counts, compares documented system/hospital row totals and identifiers, checks hospital parent-system identifiers against the system file, and discards raw bytes. For outpatient, worksheet data row counts and headers are only observed; no canonical entity or link interpretation. No row-level publication, ingestion, API or deployment claim. Other source counts require separate documentary comparison. If the actual schema differs, investigate without silently relaxing or guessing semantics. No changes to existing app or data.
